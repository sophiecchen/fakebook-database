# Fakebook Database

This is a series of work on a fictional database called Fakebook Database:
- `/database-schema`: An ER diagram of the database structure
- `/create_and_drop`: A series of scripts for creating and dropping tables according to the ER diagram
- `/jdbc`: A series of SQL queries relating to the database in a Java application
- `/mongodb`: A series of MongoDB queries relating to the database

The full project requirements are publicly available and can be found [here](https://eecs484db.github.io/) under projects 1 (Fakebook Database), 2 (Fakebook JDBC), and 3 (MongoDB).
